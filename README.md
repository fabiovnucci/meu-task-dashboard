meu-task-dashboard
Projeto de dashboard para gerenciamento de demandas desenvolvido com foco em boas práticas de estruturação e lógica de programação.

🛠️ Tecnologias Utilizadas
HTML5: Estruturação semântica do conteúdo.

CSS3: Estilização, layout responsivo com Flexbox.

JavaScript (Vanilla): Lógica de manipulação do DOM e eventos.

⚙️ Funcionalidades

Adição dinâmica de tarefas.

Remoção de itens da lista.

Validação de campos vazios.

Suporte a atalho com tecla Enter.

🚀 Como Executar
Clone este repositório:
git clone [https://github.com/fabiovnucci/meu-task-dashboard.git](https://github.com/fabiovnucci/meu-task-dashboard.git)

Abra o arquivo index.html em qualquer navegador.
